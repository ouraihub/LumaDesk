# 03 模型设置界面与交互改造

## 目标与范围

以用户提供的 AutoNote 模型设置截图及其实际组件为参考，改造 LumaDesk 的 egui 模型服务页。先整理任务和契约，再实施；本文件是后续模型的接续入口，完成项必须有验证记录，未观察到的结果不得勾选。

后续模型编辑完整对标与 SQLite 存储要求见 [04-模型管理逐项对标与存储迁移](04-模型管理逐项对标与存储迁移.md)。本文“保留JSON/不新增高级字段”仅描述此前交付范围，不作为拒绝新要求的依据；本文已完成项不能当作04新增功能已完成。

保留原生 egui/eframe 0.37.0、当前 JSON 格式、系统加密、多线路、多密钥、三协议模型目录检测、同步选择和现有聊天连接解析。不添加 UI 框架或第三方组件依赖，不改变其它设置页面的信息架构。

## 设计决策

### 页面结构

- 不重做整个应用壳的信息架构；统一 theme.rs 生成全应用中性纸面、文字、边框与强调色，保留宿主字体与图标资源。
- 平台列表：搜索、全部/已启用/已停用过滤、字母/汉字头像、名称、启用状态点；选中背景浅灰而不是整块高饱和蓝。
- 详情：服务商标题、设置按钮、最右侧带标签的滑动开关；密钥主行和检测；地址及线路设置；请求 URL 作为次要说明；模型工具栏和列表。
- 600 point 以下内容区上下排列；所有输入/模型名称按剩余宽度布局或截断，按钮不被长地址推走。
- 不复制参考项目专属品牌图形；复用字体图标时须有可访问名称与悬停说明。

### 尺寸与配色复核

参考 `aether-ui/src/styles/tokens.css` 的正文 13px、小字 11.5px、输入高 30px、小按钮 28px、圆角 8px；Switch 实现轨道 34×20px、圆钮 16px。这里用逻辑 point 还原比例，不按桌面截图缩放倍数放大。

本页工作区最大 760 point，平台列 224 point，列间 24 point；标题与列表左对齐，详情不随超宽窗口无限延伸。正文 13、小字 11.5、标题 15；纸面、边框、次要文字、链接与选中状态均为主题语义色。模型页不私自调用 set_visuals 或重建另一套默认主题。
强调色来自用户外观偏好，不固定朱红：新增浅色/深色/跟随系统、七种强调色、暖纸/纯白、舒适/紧凑，保存到数据目录 appearance.json。`src/theme.rs` 统一定义语义颜色与尺寸 Token 并映射 egui Style/Visuals；页面、弹层及共享控件消费当前主题，不重建私有默认主题。错误/警告状态不随强调色改义。语言、正文字体和正文排版不在本次新增范围。


### 交互合同

| 操作 | 提交及取消 | 失败/边界 |
| --- | --- | --- |
| 启用 | 点击立即单字段保存 | 原文件、已保存目录不变；开关回到保存状态，不提交其它草稿 |
| 名称/新增服务商 | 模态内输入，保存成功关闭 | 名称校验失败保留输入；创建后选中，新服务商无线路时提示添加 |
| 地址 | Enter/失焦且内容变化提交，显式重试入口 | 非法 URL 就地提示；保留草稿，检测不读取未保存值 |
| 线路设置/新增 | 独立编辑副本，保存成功应用；取消不写入 | 多线路互不串 ID；删除明确确认，取消不删除 |
| 密钥 | 主行可添加，管理弹层选择/添加/修改/显式查看/复制/删除 | 空值不清空原钥；失败保留草稿；离开/关闭清除明文；不得在日志输出密钥 |
| 模型 | 添加/编辑用副本，保存成功关闭；移除立即保存 | ID 非空唯一，未知能力不猜；失败保留修改/可重试，不显示假成功 |
| 检测 | 仅请求已保存线路，显示真实数量/错误 | 取消不修改模型；保留认证失败切换及响应上限 |
| 同步 | 检测后打开模态，搜索与选择，明确确认保存 | 沿用既有确认式同步，手动模型与已有能力保留；Esc/取消不应用 |
| 页面离开 | 保留原有取消网络/清理明文行为 | 设置弹层取消不能误保存输入；多 pass 不重复网络请求 |

### 角色与能力边界

截图的对话/写作/绘图角色对应参考项目独立宿主接口。LumaDesk 当前仅有文本聊天模型选择，没有写作或图像生成消费者。本次不绘制无消费者的写作/绘图角色假控件，也不借 UI 改造扩展协议与数据格式。保留已有模型默认选择与聊天选择行为；该差异必须在交付说明中明确。

模型筛选只基于现有 streaming/tools/vision 三个显式声明，不按模型 ID 猜能力。价格、上下文、推理等当前未存储/消费的字段不照搬。

## 密钥行内操作

- 默认只显示完整遮罩与眼睛；点击眼睛显式解密当前选中密钥，同行展开复制、修改、删除、隐藏按钮。再次点击隐藏时释放明文；不通过每帧解密生成局部遮罩。
- 复制仅写入系统剪贴板并提示风险；修改打开现有密钥管理并定位该密钥，空草稿不替换旧值，保存成功后清空草稿与显隐状态。
- 删除先清除明文再打开确认，取消不修改文件；确认只删指定服务商/线路/密钥，失败保留原配置和确认入口。
- 显示状态绑定 key ID，切换服务商、线路、离开设置或关闭管理弹层均清理明文；解密失败不会残留上次密钥。
- 图标来自现有 Phosphor 字体，沿用主题语义色、CONTROL_SMALL 和 RADIUS，不添加图标依赖。
